# mde（MarkDown インラインエディタ）

.NET 8 / WPF のデスクトップアプリです。

## 構成

```
mde/
├── mde.csproj
├── App.xaml / App.xaml.cs
├── MainWindow.xaml / MainWindow.xaml.cs   ← 主要ロジック
├── TableSizeDialog.xaml / TableSizeDialog.xaml.cs
└── README.md
```

## 実行方法（開発時）

Visual Studio 2022 以降で `mde.csproj` を開いて F5、
またはコマンドラインで：

```
dotnet run
```

（.NET 8 SDK と ".NET デスクトップ開発" ワークロードが必要です）

## 単独 .exe として配布する場合

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

`bin\Release\net8.0-windows\win-x64\publish\mde.exe` が生成されます。
.NETランタイムを別途インストールしなくても、このexe単体で動作します。

## 主な機能

- プレビュー画面に直接読み書き（編集ペインとプレビューペインの分離なし）
- ファイルを開くと改行コード（CRLF/LF）を自動検出して記憶し、保存時にはその改行コードのまま
  書き出します。読み込んだファイルの見た目や空行の数などが内部的に再構成される都合上、元の
  ファイルとバイト単位で完全に一致するわけではありませんが、改行コードだけは変わらないように
  しています。
- `* ` → 箇条書きに自動変換 / `#`〜`######` + スペース → 見出しに自動変換
- 箇条書き中: Enterで次の項目、Shift+Enterで項目内改行、Tabで字下げ、Shift+Tabで字下げ解除、
  空の項目でEnterキーを2回押すと抜ける（抜けた位置は字下げなしに戻ります）
- 右クリック: 見出しレベル変更、表の挿入、表内での行・列の挿入／削除、ソース⇄MarkDownモード切替
- 「```」または「```言語名」と入力してEnterを押すとコードブロックに切り替わります。閉じる```と、
  そのあとの空行が自動的に挿入されます。抜けるときはコードブロックの上下の行をクリックしてください
  （コードブロック内ではEnterキーは改行として働きます）。Tabキーでタブ文字を挿入、
  Shift+Tabで行頭のインデント（タブ1つ、またはスペース最大4つ）を1段階戻せます。
- 表: セルを直接編集、カーソルキーでセル間移動
- 左サイドペイン: フォルダビュー（一番左）とアウトラインビュー（見出し一覧、クリックでジャンプ）。
  ツールバーの「フォルダを隠す」「アウトラインを隠す」でそれぞれ個別に表示・非表示を切り替えられます。
  保存されていない変更があるファイルは、フォルダビュー上でファイル名の先頭に `*` が表示されます
  （現在開いているファイルの未保存の編集、フォルダ全体の置換などでメモリ上にのみ変更が溜まっている
  ファイルの両方が対象です）。保存すると自動的に `*` は消えます。「フォルダを開く…」で別のフォルダに
  切り替える際、`*` の付いたファイルが残っていると破棄してよいか確認したうえで開きます。フォルダを
  開くと、現在エディタに表示されている内容は（確認の有無にかかわらず）破棄されます。新しいフォルダの
  中に、それまで開いていたファイルと同じ相対パス（フォルダ内での位置とファイル名）のファイルが
  あればそれを開き、なければそのフォルダの先頭にあるファイルを自動的に開きます。
- 新規作成 / 開く / 保存（同じファイルに上書き）/ 名前を付けて保存
- 拡大・縮小（ツールバーの－/＋ボタン、または Ctrl+マウスホイール）
- 「開く…」でMarkDownファイル(.md)を選択、またはフォルダビューでファイルをクリックすると、
  **同じフォルダにある画像を自動解決して表示**
  （`<img src="images/xxx.png" ... />` やMarkDownの `![alt](images/xxx.png)` の両方に対応）
- 保存時もMarkDown形式のまま書き出し（画像タグの形式も維持）

## 既知の制約 / 今後の相談ポイント

- 検索・置換の「次を検索」「1件ずつ置換」は、対象範囲が「現在のファイル」の場合、正規表現モードでも
  実際にエディタ内で該当箇所をハイライト表示・自動スクロールします（フォルダ全体を対象にした場合は、
  他のファイルはエディタで開いていないため、検索と置換ウィンドウ内に前後の文脈をテキストで表示します）。
- 私(Claude)側にWindows/WPFのビルド環境がないため、このコードは**コンパイル未検証**です。
  ビルドエラーが出た場合はエラーメッセージをそのまま貼っていただければ、すぐに直します。
- フォルダビューは `Microsoft.Win32.OpenFolderDialog`（.NET 8で追加されたAPI）を使用しています。
  お使いのSDKバージョンでこのクラスが見つからない場合は、`System.Windows.Forms.FolderBrowserDialog`
  への置き換えが必要です（`<UseWindowsForms>true</UseWindowsForms>` を.csprojに追加）。教えていただければ
  すぐに書き換えます。
- フォルダビューは既定で `.md` / `.markdown` ファイルのみ表示します（画像フォルダ等は展開できますが
  中の画像ファイル自体は一覧に出ません）。
- 現在開いているファイルを編集した状態のまま「開く…」やフォルダビューで同じファイルを再度開こうと
  すると、未保存の変更を破棄してよいか確認したうえで、保存済みの内容に開き直します。
- コードブロックの言語指定（```csharp のような）は保持されます。「```言語名」と入力してEnterを押した
  時点で決まり、エディタ上には言語名は表示されません（ツールチップとして確認できます）が、保存・
  読み込み時には正しく往復します（GitHubや他のエディタで開いたときにシンタックスハイライトが効きます。
  このアプリ自体はシンタックスハイライトを行いません）。あとから言語名を変更するUIはありません。
- 見出しへの変更を、箇条書き項目の中の段落に対して右クリックで行った場合、リストから完全に
  抜けずその場でスタイルだけ変わる簡易実装になっています（Web版では自動的にリストの外に出ていました）。
- 画像は `<img>` タグの `src` 属性、またはMarkDownの `![alt](src)` のパスをそのまま
  開いたファイルのフォルダからの相対パスとして解決します。絶対パスや `http(s)://` にも対応しています。
- エディタに画像ファイルをドラッグ&ドロップすると、ドロップした位置に画像として挿入されます
  （`RichTextBox`は内部にテキスト編集用の独自ドラッグ&ドロップ処理を持っており、通常の
  `DragEnter`/`DragOver`/`Drop`イベントだと横取りされてしまうため、`PreviewDragEnter`/
  `PreviewDragOver`/`PreviewDrop`（トンネリング方式）で受け取るようにしています）。
  画像は**常にまずOSのTempフォルダ（`%TEMP%\mde\<このウィンドウ固有のID>\`）に
  コピー**され、そこから表示されます。同時に複数のファイルを編集している場合でも、ウィンドウ（文書）
  ごとにTempのサブフォルダが分かれるため、無関係なファイル名同士がぶつかって不要な連番が
  付いてしまうことはありません。保存（「保存」または「名前を付けて保存」）を行うたびに、その時点で
  Tempフォルダにある画像だけが編集中のMarkDownファイルと同じフォルダの `images` フォルダ
  （なければ自動作成）へ移動されます。こうしておくことで、画像を追加したあと保存せずに変更を
  破棄すれば、実際のファイル・フォルダは一切変更されないまま元の状態に戻せます。Tempフォルダ・
  `images` フォルダのどちらでコピーする際も、同名ファイルがあれば末尾に連番 `_1`, `_2`... を
  付けて重複を回避します。ウィンドウを閉じるときに、そのウィンドウ用のTempサブフォルダは
  自動的に削除されます（保存済みで既に移動済みのものは対象外です）。
- ツールバーの「検索と置換…」から検索・置換ができます。対象範囲は「現在のファイル」と「フォルダ全体
  （フォルダビューに表示中のルートフォルダ以下、サブフォルダ含む）」から選べます。「正規表現を使用する」
  「大文字・小文字を区別する」もそれぞれ切り替えられます（正規表現の置換後文字列では `$1` などの
  後方参照が使えます）。フォルダ全体を対象にした置換は、**保存するまで実際のファイルには書き出されません**
  （このアプリ内のメモリ上でのみ変更を保持します）。ツールバーの「すべて保存」を押すと、現在開いている
  ファイルと、置換などで変更されたまま保存されていない全てのファイルをまとめて書き出します。
- 「1件ずつ置換…」で、一致箇所を1つずつ確認しながら「置換」「スキップ」「残りをすべて置換」「終了」を
  選べます。これは現在のファイル・フォルダ全体のどちらの対象範囲でも使えます（フォルダ全体の場合は
  ファイルをまたいで順番に進み、各ファイルの一致箇所をすべて処理し終えると次のファイルへ移ります）。
- フォルダ全体を対象にした検索・置換の結果一覧はファイルパスごとに表示され、ダブルクリックでそのまま
  そのファイルを開けます（開いた直後に検索語の最初の一致箇所へジャンプします）。
- 表はExcelとの間でコピー&ペーストできます。Excelで選択した範囲をコピーしてこのエディタに貼り付けると
  自動的に罫線付きの表になり、逆にこのエディタの表をコピーしてExcelに貼り付けると、Excelのセルに
  展開されます。**選択したセル範囲だけを正確にコピー**できます（範囲選択せず表内をクリックしただけの
  場合や、選択が表の外にまたがる場合は、表全体をコピーします）。別のMarkDown文書（このアプリの
  別ウィンドウなど、HTML形式のクリップボードを読めるアプリ）との間でも、罫線を含めて表として
  相互にコピー&ペーストできます。タブ区切りテキストからの貼り付けにも対応しています。
- コードブロックは、通常どおり範囲選択してCtrl+Cすると中身の文字列だけがコピーされます。右クリック
  →「コードブロック全体をコピー（```込み）」を選ぶと、開始・終了の```と言語名を含む、完全な
  MarkDown形式の文字列としてコピーされます（他のMarkDownドキュメントやチャットへの貼り付け用）。
  コードブロックの中にペーストすると、常にそのブロック内の1行または複数行として（改行はブロックを
  抜けずに）挿入されます。
- エディタ上の画像はデスクトップ等へドラッグ&ドロップで書き出せます。また、画像の上で右クリック
  →「画像を保存…」でも保存できます。**書き出し先で同名ファイルが既にある場合、末尾に連番
  （`_1`, `_2`...）を付けて重複を確実に回避するのは「画像を保存…」の方です。** ドラッグ&ドロップは
  実際のファイル書き込みをWindowsエクスプローラー側が行うため、同名ファイルがあった場合は
  エクスプローラー自身の確認ダイアログが表示されることがあります（こちらはアプリ側で制御できません）。
- 画像は既定でオリジナルサイズの100%以下で表示します。横幅がエディタの表示幅を超える場合のみ自動的に
  縮小します（縦に長い画像は、縦がはみ出すだけなら縮小しません）。エディタの拡大率を100%より上げると、
  見切れない範囲でその倍率まで画像も一緒に拡大されます
